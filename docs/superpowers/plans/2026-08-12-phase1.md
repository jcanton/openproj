# openproj Phase 1 — implementation plan

**Goal:** a static, read-only viewer over the seed corpus — model, validation, scheduler, index, three
HTML pages — with no server, no auth and no writes.

**Gate 1 is the point.** Nine days of work exists to answer one question: *does the scheduler produce
dates the team argues with?* Everything here is subordinate to reaching that meeting.

**Spec:** `docs/superpowers/specs/2026-08-12-appetite-design.md`. Where this plan and the spec
disagree, the spec wins.

## Why this plan is short

Two attempts to generate a fully-expanded plan — every task with its complete test and
implementation — were rejected on audit, both times because the sections truncated mid-code. The
format writes the whole implementation twice, once as prose and once as code, and it is the right
format for handing work to someone with no context. That is not the situation. This plan fixes
**order, interfaces, and the tests that must exist**; the code is written in the working tree, under
test, one commit per task.

## Verifying a change

**Any change that touches rendered JavaScript is checked in a browser before it is
called done.** The test suite cannot execute the page, and it owns both sides of
every boundary it tests — which is why four separate escapes reached the user:

- a `\n` in a Python triple-quoted string became a real newline inside a JS string
  literal, and the whole table script died silently
- `DAGRE_JS` is a substring of `CYTOSCAPE_DAGRE_JS`, so sequential marker
  replacement inlined one library twice and another never
- removing the create form left the script wiring up a button that no longer
  existed, and the TypeError fired before the table drew
- `status` and `priority` as `Literal` fields turned one file written before a
  rename into a 500 on every page

Every one of them passed a green suite. Python-only changes do not need the browser;
anything that reaches `_TABLE`, `_DETAIL`, `_GRAPH`, `_TIMELINE`, `_NEW` or
`_COMBOBOX` does.

## Global constraints

- Python 3.12+, `uv`. Layout `src/openproj/`, tests in `tests/`.
- pydantic v2, **ruamel.yaml in round-trip mode**, python-frontmatter, networkx, jinja2, pytest,
  hypothesis.
- **No npm, no build step, no CDN.** Vendored pinned JS under `static/`.
- Strict TDD: failing test, run it, implement, run it, commit. One commit per task.
- IDs are `^(proj|pitch|task)-[0-9a-f]{6}$` and the prefix matches `kind`.
- **Only `depends_on` is stored.** `blocks` is derived. Never add a stored `blocks` field.
- **Derived data never reaches frontmatter.** No computed dates in entity files, ever.
- One implementation of each concept. Size resolution, the `blocked` predicate and the predicate
  list each exist in exactly one place — three defects found by audit were duplicate definitions
  that drifted.

## Interfaces

Fixed. Anything using a different name is wrong.

```python
# openproj/model.py
class Problem(BaseModel):
    severity: Literal["blocker", "warning"]; entity_id: str
    field: str | None; message: str; rule_version: int

class Config(BaseModel):
    schema_version: int = 1; nominal_availability: float = 1.0
    default_task_effort: float = 0.5
    holidays: list[date] = []; cycles: dict[int, tuple[date, date]] = {}

class Entity(BaseModel):
    id: str; kind: Literal["project", "pitch", "task"]; title: str
    parent: str | None = None
    status: Literal["todo", "wip", "done", "shelved"] = "todo"
    owner: str | None = None; assignees: list[str] = []
    reviewers: list[str] = []; review_waived: bool = False
    assigned_on: date | None = None; priority: int = 2
    depends_on: list[str] = []; cycle: int | None = None
    tags: list[str] = []; prs: list[str] = []
    body: str = ""; created_schema_version: int = 1

class Project(Entity): pass
class Pitch(Entity):   appetite_weeks: float | None = None
                       shaped_by: str | None = None
class Task(Entity):    effort_weeks: float | None = None

def parse_text(text: str, source: str) -> Entity
def parse_file(path: Path) -> Entity
def serialise(entity: Entity, original_text: str | None = None) -> str
def load_config(root: Path) -> Config
def load_repo(root: Path) -> tuple[list[Entity], Config]
def ancestors(entity_id: str, by_id: dict[str, Entity]) -> list[str]
def size_weeks(entity: Entity, config: Config) -> tuple[float, bool]   # (weeks, was_defaulted)
def validate_all(entities: list[Entity], config: Config) -> list[Problem]

# openproj/schedule.py
class Span(BaseModel):
    start: date; end: date
    estimated: bool = False; unowned: bool = False
    historical: bool = False; unscheduled: bool = False
    overruns_cycle_weeks: float | None = None

class Explanation(BaseModel):
    entity_id: str; text: str
    blocker_id: str | None = None; worker_busy_until: date | None = None

def working_days_after(start: date, weeks: float, config: Config) -> date
def schedule(entities, config, today) -> tuple[dict[str, Span], dict[str, Explanation]]

# openproj/index.py
COMPUTED_PREDICATES = ("blocked", "unblocked", "overruns_cycle",
                       "missing_required_fields", "review_waived")   # one definition, this one

class Index(BaseModel):
    entities: dict[str, Entity]; children: dict[str, list[str]]
    blocked_by: dict[str, list[str]]; blocks: dict[str, list[str]]
    spans: dict[str, Span]; explanations: dict[str, Explanation]
    problems: list[Problem]
    facets: dict[str, list[str]]; search_blob: dict[str, str]

def build_index(entities, config, today) -> Index
def apply_filters(index: Index, filters: dict[str, list[str]], query: str) -> list[str]

# openproj/render.py
def render_static(index: Index, out_dir: Path) -> None   # index.html, graph.html, timeline.html

# openproj/cli.py
def main(argv: list[str] | None = None) -> int
#   check <repo> | render <repo> <out_dir> | schedule <repo> --json
#   check exits 1 iff any Problem has severity "blocker"
```

`blocked` means: has at least one `depends_on` target whose status is not `done` or `shelved`.
That sentence is the definition; `apply_filters` is the only place it is implemented.

## Tasks

Each ends with a passing test suite and one commit.

### Stage A — model (3 days)

- [ ] **A1** Scaffolding: `pyproject.toml`, `src/openproj/`, pytest, ruff, `conftest.py` with a
      `seed_root` fixture. Test: package imports, and the seed corpus has 17 entity files.
- [ ] **A2** `Problem`, `Config`, `load_config`, and the two missing seed config files
      (`cycles.yaml`, `holidays.yaml`). **Do not touch `seed/config/defaults.yaml`** — it is correct
      and carries `schema_version: 2`. Test: merge of three files; fallback with no config directory.
- [ ] **A3** `Entity`/`Project`/`Pitch`/`Task`, every field Optional at the type level. Test: an
      entity with nothing but `id`, `kind` and `title` constructs cleanly.
- [ ] **A4** `parse_text`, `parse_file`, dispatch by `kind`. Test: parse
      `seed/pitches/pitch-2a7f3e--tracer-adv-port-ls-coeffs.md`, assert `id == "pitch-2a7f3e"` and
      that the body survives.
- [ ] **A5** `serialise` with ruamel round-trip. **The critical test:** parse → serialise → byte
      equality against a fixture containing comments, unusual key order and non-ASCII.
- [ ] **A6** `ancestors`, `size_weeks`, `load_repo`. Test: `ancestors` on the seed's
      task → pitch → project chain; `size_weeks` returns `(0.5, True)` when the size is absent.

### Stage B — validation (2 days)

- [ ] **B1** The rules table as data: a list of `(rule_version, applies_to, check, message)`, and
      `validate_all` walking it. Test: one rule fires, one does not.
- [ ] **B2** Status gates — `todo`, `wip`, `done` — including `review_waived` in both the `todo` and
      `wip` rules. Test: one per gate, plus a waived entity passing.
- [ ] **B3** Structural rules: title, id regex and prefix-matches-kind, dangling `depends_on`.
- [ ] **B4** **Ancestor-or-descendant dependency is a blocker.** Test asserts the exact message.
- [ ] **B5** Cycles in `depends_on`; cycles in the `parent` chain. Both blockers.
- [ ] **B6** Warnings: unparented task; reference to a shelved entity.
- [ ] **B7** **Grandfathering.** `shaped_by` is `rule_version 2`. Test: a pitch with
      `created_schema_version: 1` gets `severity == "warning"`; the same pitch at version 2 gets
      `"blocker"`.
- [ ] **B8** Integration: `validate_all` over `seed/`, asserting the exact problem set. Only the one
      `todo` pitch warns on `shaped_by` — both that rule and the size rule are scoped to `todo`, so
      no `done` entity is asked for a size. The `done` entities block on missing PRs instead.

### Stage C — the scheduler (3 days)

This is the product. Nothing below it may be skipped.

- [ ] **C1** `working_days_after`: fractional weeks, weekends, `config.holidays`.
- [ ] **C2** The ordering graph — union of `depends_on` and child→parent edges — then
      `lexicographical_topological_sort` keyed by `(priority, id)`.
      **Regression test: `test_children_are_ordered_before_their_parent`.**
- [ ] **C3** Cycle detection wired into `schedule()`: nodes in a cycle and their descendants get
      `unscheduled=True`; unrelated nodes still schedule; **`schedule()` never raises**, including on
      an ancestor-dependency that `validate_all` would have rejected.
- [ ] **C4** Duration. **Regression test: `test_three_week_appetite_is_three_weeks_not_five`.** Plus
      `test_a_task_and_a_pitch_of_the_same_size_get_the_same_duration`.
- [ ] **C5** Missing size → `config.default_task_effort`, `estimated=True`.
- [ ] **C6** `done` entities: historical point marker at `assigned_on`, no span at all if that is
      null, excluded from forward scheduling **and** capacity.
      **Regression test: `test_done_work_does_not_push_a_live_task_of_the_same_owner`.**
- [ ] **C7** Capacity: `next_free_slot`, capacity 1 per worker, **leaves only**.
      **Regression test: `test_a_parent_does_not_double_book_the_owner_of_its_only_child`** —
      the parent's span must *equal* the child's, not follow it.
- [ ] **C8** Rollup, and `overruns_cycle_weeks` against `config.cycles`.
- [ ] **C9** Explanations, populated for every scheduled entity, with `blocker_id` and
      `worker_busy_until` filled where they apply. Test asserts the exact sentence for a
      blocker-bound case and for a worker-availability-bound case.
- [ ] **C10** The three property tests, with a hypothesis strategy generating a valid random DAG:
      1. no item starts before all its blockers end;
      2. no worker has two overlapping spans;
      3. *adding an item that shares no worker and no ancestor with an existing item never moves
         that item's span* — this exact wording; the looser version is false under capacity 1.
- [ ] **C11** Golden-file integration over `seed/`, and **a hand-check of the output against the
      spec's worked algorithm before trusting it.** The last two scheduler bugs were both found this
      way and neither would have been caught by a unit test.

### Stage D — index and filters (1.5 days)

- [ ] **D1** `build_index`: children map, `blocks` as derived reverse edges. Test: no stored `blocks`
      field is ever read.
- [ ] **D2** Spans, explanations and problems wired in.
- [ ] **D3** Facets and `search_blob`.
- [ ] **D4** `apply_filters`: AND across fields, OR within a field, one test per predicate in
      `COMPUTED_PREDICATES`, plus substring search and a combined case.

### Stage E — the viewer (2.5 days)

- [ ] **E1** Vendor Cytoscape.js, dagre, cytoscape-dagre and frappe-gantt into `static/` with pinned
      versions and recorded checksums. Test: no rendered page references an external URL.
- [ ] **E2** `index.html` — the table. Index serialised to a JSON blob in the page; filtering,
      sorting, grouping and search client-side in vanilla JS; **all state in query parameters**.
      Derived columns visually distinct. Persistent blocker count.
- [ ] **E3** `graph.html` — Cytoscape + dagre, left-to-right, compound nodes for the three-level
      zoom, colour by status, border by priority.
- [ ] **E4** `timeline.html` — frappe-gantt grouped by owner, cycle rules, today line, hatching for
      `estimated` and `unowned`, explanation on hover. **Evaluate frappe-gantt against the seed
      corpus in this task and record the result** — its behaviour at scale is unverified, and the
      fallback is a hand-rolled SVG Gantt.
- [ ] **E5** `render_static` writing all three.

### Stage F — CLI and end to end (1 day)

- [ ] **F1** `main(argv)` with `check` / `render` / `schedule --json`; exit 1 on any blocker.
- [ ] **F2** Root `README.md` — the repository has none.
- [ ] **F3** End to end: render `seed/`, assert all three pages exist and contain expected content.

## Gate 1

Show the timeline in a planning meeting. **Continue to Phase 2 only if someone argues with a date.**
Silence or polite agreement means stop and adopt OpenProject — one week spent, and a useful static
page either way.

## Deferred to Phase 2

Server, OAuth, writes, compare-and-swap, SSE, `derived/` in CI, PR→status automation, per-record
history.
